# Laboratorio 11 — Comunicación entre componentes

Aurora Cinemas continúa el proyecto del laboratorio 10. Para ejecutarlo: entra a `cinema-app/`, corre `npm install` y `npm run dev`. También puedes usar `npm run lint`, `npm run build` y `npm test`.

El proyecto usa React 19, Vite 8, Vitest 5, React Hot Toast y Swiper. Autor: Leonardo Ronda.
